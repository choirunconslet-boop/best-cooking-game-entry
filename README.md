# Sizzle & Serve — Warung Rush

Run a tiny warung kitchen through the lunch rush. Grab ingredients from the pantry, grill patties, chop lettuce and tomatoes, fry the fries, stack each dish on the plate exactly as the order board asks, and ring the serve bell before the customer's patience runs out. Earn 120 coins before the 2½-minute shift ends — but if 3 customers walk out, the warung empties and the shift is lost.

Move with WASD or arrow keys, use a counter with E, Space, or a click. M mutes the synth sizzles and jingles; R restarts.
